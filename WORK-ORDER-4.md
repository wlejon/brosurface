# Work Order 4 — isolation hardening, vocabulary extension, honest leverage, batch 3

Status: authored 2026-08-22 after independent verification of the WO-3 report.

## What verification found (drives M1 — read carefully)

The good: all five commits verified, tree clean, `audit_gen` green when run independently,
spot-checked `diff.patch` bundles apply cleanly at bro `a2311f34`, per-namespace
over-ceiling justifications present in the playbook and ledger, and the mutation gate
passed against a NOVEL verifier-authored mutation (a marker attribute inserted into
`settings.idl` propagated to `.d.ts`, docs, and the qjsbind TU with zero `gen/` edits).
The generation model is real.

The violation: at 19:13–19:15 on 2026-08-22, generated TUs were written into the **live**
`D:/projects/bro` tree (`src/bronze_host/host_abort.cpp`, `host_parser.cpp`) and the
**live** brokit checkout (`third_party/brokit/src/api/abort.cpp`), then restored at
19:22. The report claims scratch-worktree isolation and does not disclose this. No
commits were made and the restoration was clean — but restoring with `git checkout`
would have silently destroyed any uncommitted user work sitting in those files. That is
the exact catastrophe the isolation rule exists to prevent. This does not invalidate the
order's results; it does mean isolation must become machine-enforced instead of promised.

Minor hygiene, also for M1: committed `out/qjs/` artifacts have one-line drift against
the current emitters (mic, settings — an emitter tweak landed after the artifacts were
committed), and batch-2 qjs artifacts exist only under `integration/`, not `out/`, so
`out/` is no longer the regenerable mirror of the emitters at HEAD.

## Milestones

### M1 — isolation, machine-enforced
1. Every tool that touches a bro/brokit checkout (`verify_integration_bundle.mjs`, any
   equivalence runner) must REFUSE to operate on a working tree that is not a scratch
   worktree: assert the target is a linked worktree (`git rev-parse --git-dir` differs
   from `--git-common-dir`) AND lives under the scratch root; exit fatal otherwise. A
   `--live-tree-i-am-sure` override may exist but must print a red warning and is never
   used by automation.
2. Pre/post guard: each verify run records `git status --porcelain` of the LIVE bro and
   brokit trees before starting and asserts it is unchanged after; a difference is a
   fatal error that prints the diff.
3. State plainly in the M1 report what the WO-3 process did on 2026-08-22 19:13–19:22
   and which tool wrote to the live trees (find it — the fix must name the cause, not
   just add guards).
4. Artifact mirror hygiene: regenerate ALL committed `out/` artifacts at HEAD so `out/`
   is byte-exact against the current emitters; commit batch-2 artifacts to `out/` the
   same way batch-1's are; add `tools/check_out_fresh.mjs` (regenerate to temp, diff,
   nonzero on drift) to the standing acceptance suite.

**Acceptance:** demonstration that the runner refuses a live tree and accepts a scratch
worktree; the pre/post guard shown failing on a deliberately dirtied live tree;
`check_out_fresh` green at HEAD; the named root cause of the 19:13 incident.

### M2 — vocabulary extension from the custom-block census
The honest metric did its job: 4,183 custom LOC across 17 surfaces, eleven over the 15%
ceiling, four at 85%+. At 90%+ the IDL is a container for a hand-written binding — the
transcription problem moved from `gen/` into `[cpp_body]`. Extend the vocabulary instead:

1. Cluster all custom blocks across the 17 IDLs by recurring pattern. Expected clusters
   (verify, don't assume): JS-class/lifecycle-callback registry (customElements),
   chunked/streaming reads with device state (mic, rave, motion), persistent keyed
   store with change dispatch (settings), engine-object handle + method forwarding
   (terrain, gizmo). Report the cluster table with LOC per cluster.
2. Extend the IDL vocabulary (schema + all emitters, generically) with the two or three
   shapes that cover the most custom LOC. Re-emit affected namespaces, re-run their
   equivalence protocol, refresh their bundles.
3. Target: at least four of the eleven over-ceiling namespaces drop under 30% custom.
   Where a namespace stays high, one sentence on why the remaining logic is genuinely
   engine-specific — the WO-3 discipline, kept.

**Acceptance:** cluster table; before/after custom fractions per touched namespace;
mutation gates re-run green (the verifier will use novel mutations against the NEW
vocabulary attributes specifically); equivalence re-run output tails at a stated bro SHA.

### M3 — honest leverage metric
`(artifact LOC − custom LOC) / (IDL LOC − custom LOC)` reported as **derived leverage**
alongside the existing gross number, per namespace and in aggregate, in both the
playbook and the coverage ledger (regenerated by tooling, not hand-edited). The WO-3
gross average (3.82x) counts hand-written lines in both numerator and denominator;
derived leverage is what actually scales.

**Acceptance:** regenerated ledger + playbook showing both metrics; the tail re-priced
using derived leverage from post-M2 actuals.

## Hard rules

Unchanged from Work Orders 1–3, now with teeth from M1: never commit or push in
`D:/projects/bro`, `D:/projects/bronze`, brokit, or any sibling — and never WRITE into
their live working trees even transiently; scratch worktrees only, pruned when done;
never delete existing build dirs; bash with `cmd //c` vcvars wrapper for MSVC;
foreground blocking commands only; never `--no-gpu`; no native dialogs; per-milestone
commits, full technical messages, no trailers, `git add` specific paths, never push.
Reports are independently re-verified: novel mutations against new vocabulary, live-tree
cleanliness checked before and after, and undisclosed side effects on sibling trees are
treated as invalidating the report.

## Definition of done

Isolation the machinery enforces rather than promises; a vocabulary that absorbs the
recurring custom patterns so the worst namespaces become mostly declared rather than
mostly carried; leverage numbers that price the tail from derived output only; six more
surfaces bundled; and one command that proves the whole repo healthy from cold.
